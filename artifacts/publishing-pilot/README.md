# The Things We Carry — editable publishing pilot

Open `the-things-we-carry.apocaproject.json` using **Open Project** on the Design
Space dashboard. It contains a cover, guide and ruled worksheet created through
the ordinary editor controls in `e2e/document-publishing.spec.ts`.

All manuscript text is demonstration copy. The botanical illustration is an
original test asset drawn for this pilot and imported using Add photo. Text,
paragraph spacing, dividers, writing areas and artwork remain editable.

Use Publishing → Review all pages, then Export → PDF with embedded fonts.
Prepare Letter and A4 separately using Apply paper to all pages; select Export in
grayscale for the grayscale edition. See the publishing workflow guide in docs.

This is an editable software demonstration, not the final WitchClick product or
a physically print-proofed journal.
